# 警来帮 · 智慧寻物（群众端 H5）

警务便民「智慧寻物」服务台群众端，单文件 HTML，开箱即用，适合投屏 / 大屏 / 手机演示。

## 功能

- 🔍 **丢失登记（LF）**：语音或文字描述丢失物品，生成单号，系统自动匹配疑似拾获单
- 🎒 **拾获上交（HD）**：登记拾获物品，自动生成 **6 位上交码** 供核验
- 📋 **查询 / 取件**：凭单号或取件码查询进度
- 🎯 **自动匹配**：按物品名称 + 地点关键词为丢失单和拾获单做匹配
- 🧑‍✈️ **民警核对**：匹配后由民警核对生成 **取件码**，群众凭码取件并核销（比真实系统多一道民警把关，防止乱报）
- 🎤 **语音交互**：浏览器原生 Web Speech API（ASR + TTS），不支持时自动降级为文字表单
- 💾 **零后端**：数据存浏览器 localStorage，刷新不丢

## 使用

直接用浏览器打开 `index.html` 即可。推荐 Chrome / Edge（语音识别支持最好）。

> 语音识别需在 `https://` 或 `localhost` 下使用，`file://` 直接打开时可改用手动填写。

## 演示流程

1. 走「我捡到东西」登记一件物品 → 拿到 **上交码**
2. 走「我东西丢了」登记相同物品 → 系统提示 **已匹配**
3. 进入丢失单详情 → 「民警核对 · 生成取件码」
4. 「查询进度 / 凭码取件」输入取件码 → 确认取件核销，两单办结

## 目录

```
index.html   # 全部界面、逻辑、语音、数据层
```

## 后续接入真实后端

把 `localStorage` 读写替换为 `/api` 调用即可：记录接口、匹配接口、取件核销接口。界面与状态机可保持不变。
